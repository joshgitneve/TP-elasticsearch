# Puis créez une data view offres (champ temporel date_publication), élargissez la période à « Last 1 year » et parcourez les documents dans Discover.

Créer la data view

Les intitulés peuvent varier un peu selon la version de Kibana.

# http://localhost:5601, connecté avec elastic.
Menu ☰ → Stack Management (tout en bas) → section Kibana → Data Views.
Create data view, puis :
Name : offres ;
Index pattern : offres. Kibana affiche à droite les index qui correspondent : vérifie que ton index apparaît ;
Timestamp field : choisis date_publication dans la liste. Seuls les champs de type date y figurent, et c'est grâce à ton mapping qu'il est là.
Save data view to Kibana.

# La parcourir dans Discover
Menu ☰ → Discover.
En haut à gauche, sélectionne la data view offres.
En haut à droite, le sélecteur de période (l'icône calendrier) : choisis Last 1 year.
